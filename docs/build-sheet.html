US Senate 2026 — Power BI build sheet (prototype, model v3)

Canvas 1280 x 720 px. Format page > Canvas settings > Type: Custom. Every box is drawn at true size and its badge gives X, Y, Width, Height for Format > General > Properties.
The rule this report is built around: an incomplete or unverified figure must never be able to pass as a final result. Three mechanisms enforce it — the quality strip on page 1, the status line on every race, and the headline_eligible filter on every measure a reader might quote. Only 3 of 35 races currently qualify for a margin figure.

Build order

  1. Power BI Desktop, in the folder D:\portfolio\senate 2026\data (adjust to wherever you put the files).
  2. Home > Manage Parameters > New: name SourceFolder, type Text, value = that folder. Why: one place to repoint the whole model.
  3. Create the queries from 'Senate 2026 Power Query.m', starting with fnLoad. Why: it keeps state_fips and all ID columns as text, so leading zeros survive.
  4. Close and apply, then Model view and build the relationships in the table below. Set DimRace to RaceQualityFlags to filter BOTH directions. Why: without it the quality flags cannot reach the result facts and every headline measure silently returns everything.
  5. Create a blank query named _Measures, load it, hide its placeholder column, then paste the measures from 'Senate 2026 DAX Measures.txt'.
  6. Build the pages in the order below. Page 1 last if you prefer, since it summarises the rest.
  7. Set page 3 as a drillthrough page on DimRace[race_id]. Why: it keeps the race detail out of the main navigation.
  8. Do not add any visual that shows margin_pct without the margin_eligible filter. Why: it is the one number a reader will quote, and only three races support it.

GrainText box24 / 60 / 404 / 300GRAIN DimRace: one Senate seat contested in 2026 (35). FactCandidateResult: one candidate in one race, current best evidence (169). FactResultObservation: one candidate's votes from one source at one time, append-only (159). FactCandidateFinance: one FEC candidate ID (619). FactRaceRating: one rater's rating of one race (210, all quarantined).
Source hierarchyText box444 / 60 / 404 / 300SOURCE HIERARCHY, strongest first 1. Certified state result — none exists yet. 2. Official state election authority, unofficial count — 6 races. 3. Media aggregator count — 27 races. 4. Media projection only — 0 races remain on this alone. 5. Pending — 2 races. A lower tier is never used when a higher one exists for the same race, and the superseded observation is kept.
Calculation rulesText box864 / 60 / 392 / 300CALCULATION RULES CURRENT-BEST SELECTION RULE: source tier first (official state authority beats media aggregator), then completeness of reporting units, then recency. A later timestamp alone never promotes a record. Headline and margin measures filter headline_eligible = Y: a complete count from the state authority with no integrity flag. Three races qualify. Montana is excluded from every headline figure because its source page carries a TEST marker. vote_share is computed as candidate votes / published race total, and reconciles to each source's own percentages. Overvotes and undervotes are never counted as votes. Seat totals add 34 Democratic-caucus seats not up in 2026.
Reporting period limitsText box24 / 376 / 616 / 274REPORTING PERIOD LIMITS FEC candidate totals cover different periods by candidate: only 108 of 619 filers report through 14 October 2026, and 286 state no period at all. Money is comparable only within one comparability_cohort, and the finance page defaults to a single cohort. Finance covers to 14 October at the latest; results are from 3-4 November. The two are separate facts and are never summed or shown as one period. FEC candidate totals already aggregate a candidate's authorized committees, so summing by candidate cannot double-count. Rebuilding them from committee files without removing internal transfers would.
Known exceptionsText box656 / 376 / 600 / 274KNOWN EXCEPTIONS South Carolina: Senator Lindsey Graham died 11 July 2026; his sister Darline Graham was appointed and won the nomination. The race table is corrected and the original values retained. Maine: ranked-choice voting, figures are round-one counts. Nebraska: Dan Osborn ran by petition, not as a party nominee. Ohio: the FEC reports Sherrod Brown's activity under a PAC that is not an authorized committee, so his candidate total may understate. Wyoming: overvotes and undervotes are published and excluded here. Texas: the state's older results system defaults to the 2024 election; its figures were rejected.
